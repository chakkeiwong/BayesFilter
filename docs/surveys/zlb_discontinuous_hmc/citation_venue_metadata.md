## Metadata limitations

The ResearchAssistant mission could not bootstrap its configured OpenAlex
provider and terminated with `terminal_blocked_bootstrap_unavailable`. Direct,
read-only OpenAlex queries supplied the table above, but one later exact request
was rate-limited. Crossref confirmed DOI metadata for selected published works.
No citation count, venue, or ranking was used to select a mathematical claim.
The 2026-08-19 block was likewise obtained by direct read-only OpenAlex and
Crossref queries; one Semantic Scholar search request was rate-limited and its
result marked unavailable rather than retried aggressively.
