## Historical `CE-07`: Actual-SV Fixed-Square Failure Localization

The Actual-SV model parameter is not leaving its physical domain.  The executed
coordinate vector is

\[
\theta=(\Phi^{-1}(\gamma),\log\beta)
      =(0.2533471031357997,-0.916290731874155),
\]

and the implementation maps it to `gamma = Phi(theta[0])` and
`beta = exp(theta[1])`.  All four `1e-5` endpoint perturbations therefore keep
`0 < gamma < 1` and `beta > 0`.

At each nonterminal time, the frozen square TP chart selects four teacher
particles for four features:

\[
 f(x)=(1,x,x^2,\text{continuation-likelihood}_{16}(x)).
\]

With the center-prepared anchor indices and row scales held fixed, runtime
solves the square moment system

\[
 M_t(\theta) w_t(\theta)=m_t(\theta).
\]

The chart requires finite, full-rank, adequately conditioned solutions with
every component of `w_t` strictly positive.  A nonpositive weight means the
teacher target moment lies outside the positive simplex generated by those
four frozen anchor feature columns.  The implementation correctly fails closed
and poisons claim-bearing outputs in that case.

The center-only preparation constructed 999 charts.  Its weakest center chart
is time index 748 (zero based), with minimum weight
`3.58612655e-7`.  A deliberate CPU-XLA localization using the exact frozen
preparation and loop core produced:

| Evaluation | First invalid time | Minimum weight at time 748 | Result |
| --- | ---: | ---: | --- |
| center | none | `+3.58612667e-7` | valid |
| `gamma_unconstrained - 1e-5` | 748 | `-4.22267303e-6` | invalid |
| `gamma_unconstrained + 1e-5` | none | positive; global minimum `1.22184967e-6` at time 203 | valid |
| `log_beta - 1e-5` | none | positive; global minimum `1.21790230e-6` at time 203 | valid |
| `log_beta + 1e-5` | 748 | `-5.23620186e-6` | invalid |

The 252 invalid entries reported after time 748 are cumulative recursion flags,
not 252 independent first failures.  The decisive event is the first negative
weight at the center's weakest chart.
