# Phase 0D control and combination execution

Question: do the real LEDH/KDM endpoints and independent coefficient fitting compose correctly? Baseline is unchanged canonical analytical LEDH on an affine Gaussian fixture. Integrated KDM and resampling IWSG retain their different finite targets. Kalman supplies the exact model score. This is a 48-row mechanics study, not the scientific comparison or a tuning artifact.

The control is the mean of translation/log-scale density scores of a four-component Gaussian mixture. Pilot centers come from independent prior innovations; covariance equals the model initial covariance. These density parameters are frozen for the artificial control derivative. Component uniforms are independent; normal innovations are shared with LEDH initialization. Conditional on the pilot, the control has exact mean zero. Coefficients are fitted using calibration errors and frozen for validation. The blend separately minimizes oracle calibration MSE, with no expectation-preservation claim. Two calibration and two validation datasets each have four particle replicates; claim datasets are untouched.

Pass criteria: actual numerical constituents complete, all outputs finite, initial/bandwidth derivative tests pass, control identity checks pass, disjoint datasets and complete paired coverage, full-rank calibration design, coefficient fitting uses calibration only. A missing constituent or altered data/target invalidates assembly. MSE and dataset MCSE are descriptive diagnostics, never promotion criteria in this fixture. A worse combination is a candidate failure/repair trigger; it does not invalidate the harness.

Assumptions: N=8,T=3,d=2, four pilot components and eight coefficient-fit rows are deliberately small implementation fixtures, not justified scientific defaults. Existing numerical controls are mechanics hypotheses with no per-scope tuning claim. Their purpose is to expose wiring/centering errors cheaply. Poor rank, enormous coefficients or validation loss flag inadequate calibration before larger studies. Unconstrained blend coefficients follow the derived quadratic optimum; there is no unreported clipping or ridge. No score bias removal, stochastic ranking, nonlinear coverage, full KDM lifecycle admission or default promotion follows from a pass.

Skeptical audit: the exact Gaussian solution is an oracle, not a benchmark a particle method should beat. The shared innovation preserves both marginal laws; an independently sampled conditional-zero control with no shared estimating randomness would have no useful covariance. Calibration/validation are separate; fitting uses no claim observations. The numerical budget is 600 wall seconds, at most55 attempts, two per row, charged to the existing engineering slice. Stop for invalid targets/artifacts or budget exhaustion; repair local failures within the unchanged contract.
