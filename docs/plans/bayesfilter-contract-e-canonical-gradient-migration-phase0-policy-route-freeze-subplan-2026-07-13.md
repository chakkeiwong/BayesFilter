## Phase Objective

Bind the owner's Contract E route decision into repository policy and a
machine-auditable migration inventory before any reset mathematics or schema-v2
work. Freeze the canonical reset identifier, classify every current LEDH reset/
value/gradient route, and immediately revoke admission/default/leaderboard/HMC
eligibility from historical raw-barycentric and v1 artifacts while preserving
them as evidence.

## Entry Conditions Inherited From The Master Program

- Contract E--Chol is the only reset semantics eligible for canonical LEDH
  value, gradient, admission, leaderboard, default-readiness, or HMC-facing use.
- Raw-barycentric derivatives are historical diagnostics and wrong relative to
  the canonical target even if locally correct for their own scalar.
- Contract E implementation correctness remains unproved until later gates.
- Existing dirty work must be preserved.
- No detached execution, package install, destructive git action, or public
  release is authorized.
- The master program and this subplan must pass local consistency checks and a
  bounded material review before policy editing begins.
- Immediate fail-closed revocation is required in this phase. The absence of a
  working canonical replacement is not permission to fall back to raw reset.

## Claimed Target And Quantity Computed

This phase computes no scientific likelihood or gradient. It creates governance
and inventory artifacts. A Phase 0 pass establishes only that future code and
artifacts have one explicit route target and fail-closed historical boundaries.
It does not establish mathematical, numerical, or scientific correctness.

## Exact Next-Phase Handoff Conditions

Phase 1 may begin only if:

- the master review is converged or a documented Codex substitute review finds
  no material blocker;
- `AGENTS.md` contains the scoped owner policy without damaging existing text;
- the JSON manifest parses and every route/consumer entry has exact anchors;
- canonical reset and derivative-composition identifiers are frozen;
- v1/raw artifacts are explicitly historical, non-upgradeable, and rejected by
  every current canonical admission/default/leaderboard/HMC-facing consumer;
- forged canonical metadata cannot make a raw route admissible;
- the canonical route factory is required by policy and schema-v2 handoff, while
  no caller-stamped identity is treated as proof of execution route;
- the unresolved Kalman-gradient margin remains visible rather than invented;
- focused checks pass;
- the Phase 0 result directly classifies the policy target versus unproved code;
- the Phase 1 normative-mathematics subplan is drafted and includes time ordering,
  normalization, covariance denominator, Cholesky orientation, ridge policy,
  fixed randomness, active sets, complete direct-plus-transport pullback,
  scale-aware veto thresholds, FD ladder, and statistical-design freeze.

## Stop Conditions

Stop and write a blocker result if:

- an unexpected concurrent edit appears in an in-scope file;
- the owner directive cannot be represented without conflicting repository
  policy;
- active call sites cannot be classified from local source;
- the Phase 1 mathematical specification would require an unapproved scientific
  decision that cannot remain an explicit later gate;
- five materially distinct review/repair rounds fail to converge;
- the visible campaign budget cannot support a valid close record.

## Phase-End Protocol

1. Run all focused local checks.
2. Write the Phase 0 result or blocker result.
3. Classify any failure as governance, inventory, artifact, or authority failure.
4. Draft or refresh the Phase 1 normative-mathematics subplan.
5. Review the Phase 0 result and Phase 1 handoff when material.
6. Update the execution ledger and stop handoff.
7. Advance only when the exact handoff conditions pass.
