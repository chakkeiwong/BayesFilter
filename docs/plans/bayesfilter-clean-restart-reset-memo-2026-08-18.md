## Restart Boundary

This commit is the repository restart boundary for the current BayesFilter
working batch. Authored implementation, tests, benchmark harnesses, plans,
reset/result notes, and compact evidence that supports a stated gate remain
trackable. Generated execution state is local and ignored. The boundary does
not reinterpret a failed candidate as a failed research direction and does not
promote any unresolved lane.

records, audit/verification receipts, and retained-draw receipts. These files
