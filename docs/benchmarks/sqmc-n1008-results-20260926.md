# SQMC 1,008-particle score diagnostic — 2026-09-26

The earlier 12-particle run was a mechanics and finite-difference check. It was too small to answer whether the finite-particle scores are accurate. This bounded run uses 1,008 particles, the same P44 three-state model, the same parameter vector, and the same two saved observations. The Contract-E reset design requires the count to be divisible by six; 1,008 matches the earlier campaign count. The results below use raw score components and absolute error against the exact Kalman score.

All four routes completed 72 finite GPU cells: the two original filter seeds (93001 and 93002) plus eight fixed additional filter scrambles for each dataset and route. The exact observations were replayed from the earlier traces with maximum absolute difference 0; the exact Kalman values and four-component scores matched the saved oracle. Graph and XLA GPU results matched at the checked tolerance for every route on the 93001 original input. The run used TensorFlow FP64 with TF32 disabled as a reference-precision diagnostic, memory growth, and transport chunk K=1008.

The 1,008-particle run answers the immediate objection: testing only 12 particles was inadequate for an accuracy conclusion. It also shows why the earlier 93001 anomaly should not be described as a general derivative bug. Three Hilbert routes move from visibly wrong N=12 first scores to values close to the exact score at N=1,008, while the IID route remains noisier on that seed. Remaining discrepancies may combine finite-particle error with flow discretization and the frozen reset/correction settings. This run does not prove convergence or exclude an implementation error elsewhere.


## Interpretation audit and inference status

The mathematical target is the exact Kalman log-likelihood gradient. The
implementation returns the analytical recursive score of a finite particle
program with Contract-E reset and fixed numerical controls. Their values
differ, as the raw component tables show. The reduction in the 93001
discrepancy supports the small-cloud explanation for that case. GPU graph/XLA
parity proves agreement of those two executions only. The previous N=12
finite-difference checks provide local derivative evidence; no finite-difference
check at N=1008 was performed here.

Post-run skeptical review: the strongest alternative explanation for remaining
error is fixed numerical approximation, especially two flow substeps, combined
with randomization. More particles alone cannot eliminate every such error.
This is also a change in cloud realization, not a nested coupling proof.
A systematic discrepancy persisting after a particle ladder and separately
checked numerical controls would weaken the small-cloud explanation. A failed
finite-difference check on a fixed smooth branch would point to derivative
implementation. The weakest evidence is the two-step horizon and narrow data
selection. No method or numerical setting is promoted by this run.
