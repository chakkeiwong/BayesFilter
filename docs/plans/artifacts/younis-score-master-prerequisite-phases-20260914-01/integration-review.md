## Skeptical dependency review

- Bootstrap: Phase 0A requires existing developer tools. Phase 0B builds its
  own tests and coordinator; no unbuilt service is an entry condition.
- Admission: implementation phases produce and run the tests reused in Phase
  1. Failed admission returns to the phase responsible for the implementation.
- Scope: dependencies apply to each study. A Gaussian baseline and exact FD
  mechanics can proceed without completion of unrelated KDM, covariance, or
  twisting implementations. Later models use their own Phase 0G work.
- Repairs: a failed candidate does not invalidate the entire program. A
  validity defect blocks affected evidence; source or scope changes trigger
  invalidation and applicable retuning. Outcome-informed repairs use fresh
  partitions. A repair revises work rather than creating a same-version
  circular launch prerequisite.
- Completion: terminal audit is not the first opportunity to implement the
  required software. Missing active integrations remain unfinished master
  work; they cannot become silently omitted rows.
