For this repository, Contract E--Chol is the only reset semantics eligible for
canonical LEDH value, gradient, score-admission, leaderboard, default-readiness,
or HMC-facing claims. The canonical reset identifier is provisionally
`contract_e_chol_v1`; Phase 0 freezes the exact identifier before schema work.

All raw-barycentric reset routes are historical diagnostics. This includes both
compact forward-sensitivity and full-history reverse implementations. A
derivative can be algebraically correct for a historical raw-barycentric scalar
while still being wrong relative to the owner-selected canonical Contract E
target. Such a derivative must not be admitted or relabeled as canonical.

This owner directive selects the route that may seek admission. It does not prove
that the existing Contract E implementation, a new streaming implementation, or
its likelihood and gradient are correct. Those claims remain gated by the
evidence contracts below.

Contract E ensemble-covariance restoration is distinct from Algorithm-1
per-particle covariance carry. The latter does not repair covariance removed by
barycentric projection of the ensemble cloud.

## Claimed And Computed Quantities

The canonical finite computation to be implemented is

```text
fixed model inputs and fixed random streams
  -> LEDH/PF-PF proposal and corrected weights
  -> current likelihood increment
  -> finite streaming transport with explicit row-mass output
  -> Contract E--Chol reset with fixed residual design and declared ridge policy
  -> next-time particles and uniform weights.
```

The claimed gradient is the total derivative of that same finite program. It is
not the derivative of raw `T @ X`, a stopped-scale transport, a separately
compiled algebraic reconstruction, or the exact Kalman likelihood. Kalman is an
exact oracle for the intended LGSSM observed-data likelihood and therefore a
scientific comparison target, not a substitute definition of the finite LEDH
scalar.

### Phase 1: Normative Contract E Mathematics

Before implementation, write and check the normative finite-program mathematics:
likelihood-increment/reset time ordering; normalized-weight convention;
population versus sample covariance denominator; row-mass quotient; Cholesky
orientation; fixed residual design; admissible ridge policy; floor/clip/branch

```text
G_X = G_X^moments + G_X^transport
G_w = G_w^moments + G_w^transport.
```

Freeze dtype- and scale-aware numerical veto thresholds, the FD step-size/near-
zero policy, and the Phase 8 paired statistical design before results are seen.
If a scientifically defensible Kalman-gradient equivalence margin cannot be
derived, preserve the explicit human-decision gate.

### Phase 2: Forward/Score Schema V2 And Canonical Factory

Create explicit semantic identity fields for reset contract, row normalization,
residual design, ridge policy, derivative route, prepared-input hash, and source

### Phase 3: Production Cloud-Level Contract E Module

Move the reset mathematics from benchmark-only code into an owned TensorFlow/TFP

moment/direct-weight and transported-cloud adjoint components. Keep the historical

### Phase 4: Streaming Composition And Production Feasibility

Extend streaming transport to expose numerator, row mass, and quotient-correct
