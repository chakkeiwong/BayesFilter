## Mathematical target and source audit

The local primary source is `.localresources/papers/guarniero-johansen-lee-2017-iterated-auxiliary-particle-filter.pdf`: Section 3.3, Algorithms 3–4 (parsed text lines 650–687), and Section 5.1, equations (15)–(16) (lines 908–946). Original-author code has not been located; code parity remains unchecked. The existing corrected Gaussian-plus-floor psi-APF consumer has normalization, finite-program derivative and independent final-stream tests. Reuse that consumer rather than create a competing density/correction implementation.

For positive targets y_i, equation (15) minimizes sum_i (p_i(m,Sigma) - lambda*y_i)^2. The scale optimum at fixed Gaussian is lambda = sum(p_i*y_i)/sum(y_i^2). The audit at `artifacts/younis-kdm-score-master-20260914/run-20260914-140520-01/iapf-density-fit-audit.md` proves that the unrestricted global minimizer can fail to exist. This implementation therefore promises a finite bounded numerical fit of that same objective, not a global argmin. A compact mean box and positive lower/upper diagonal scale bounds give existence of a bounded optimum by continuity, but do not prove the numerical optimizer finds it.

Let c and s be the unweighted cloud mean and coordinate standard deviations. Optimize u=(m-c)/s and v=log(sd/s). Bounds on u and v must be explicit caller settings. Zero cloud scale is an invalid fit, not silently ridged. Divide every Gaussian density by the fixed density C=(2*pi)^(-d/2)/prod(s), and scale targets by their fixed maximum. Profiling lambda after these transformations multiplies the original objective by the fixed positive factor 1/C^2; it does not replace density loss with correlation or log loss. For r_i=p_i-lambda*y_i, the envelope derivative is

    dL/dm_j = (2/n) sum_i r_i*p_i*(x_ij-m_j)/sd_j^2,
    dL/dlog(sd_j) = (2/n) sum_i r_i*p_i*((x_ij-m_j)^2/sd_j^2 - 1).

The lambda derivative cancels because sum_i r_i*y_i=0. The implementation uses these analytical gradients, projected backtracking descent, finite iteration/line-search caps, and a projected-gradient stopping check. No autodiff, pfor or NumPy is needed. Report finite loss, normalized shape residual, physical covariance scales, fitted log lambda, boundary activity, iteration count and convergence separately. A small absolute density loss alone cannot admit a fit.

Algorithm 3 builds targets backward from g(x_t,y_t)*f(x_t,psi_{t+1}), with psi_{T+1}=1. Algorithm 4 begins with exactly constant twists, repeats independent particle runs and fits, uses the latest k+1 likelihood values, doubles N only after a complete equal-N window that is not nondecreasing, and performs an independent final run after convergence. Check l>k for termination as written in the paper; do not use a partial window to grow N. The local conventions are sample standard deviation and nondecreasing monotonicity. Stable scaling of likelihoods in the CV calculation changes neither ratio nor ordering. If caps on iterations or particles are reached, return a bounded failure; do not pretend convergence.

The existing consumer integrates the latent initial x0 by particles before the first observation. This is an explicit initial-state Monte Carlo extension, not identity with the paper's analytically normalized initial-state example. Preserve that target and its full six-parameter derivative. Final fit coefficients, realized particle count, ancestor labels and mixture labels are held fixed for the final finite-program derivative. That derivative is not claimed to be an unbiased marginal-score or expectation-gradient estimator. Discrete fit adaptation is offline and frozen; its branch derivatives are not part of this target.
