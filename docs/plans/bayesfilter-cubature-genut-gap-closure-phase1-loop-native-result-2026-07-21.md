## Outcome

The candidate core was converted from Python-controlled recursion to a
TensorFlow/XLA-native implementation. Sinkhorn iterations and horizon recursion
use `tf.while_loop`; histories use `tf.TensorArray`; Contract E reset tangents
are batched over parameters. The compiled runtime contains no Python loop,
NumPy import, or host conversion.

The dynamic-horizon scalar ladder passed for `N=12`, `T={2,10,50}`:

| T | Compile seconds | Warm seconds |
|---:|---:|---:|
| 2 | 2.736 | 0.0030 |
| 10 | 1.887 | 0.0066 |
| 50 | 1.655 | 0.0647 |

All values, scores, and reset residuals were finite. Compared with the prior
static-Python-loop implementation, the `T=50` compile time fell from about
`73s` to `1.7s` on the same scalar diagnostic scope.
