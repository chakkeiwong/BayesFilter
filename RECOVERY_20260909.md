## Lessons

### For Future Agents

1. **Verify the task explicitly** before starting work:
   - Read the user's instruction
   - Check what branch should be used
   - Check what the actual task is
   - Do not assume based on conversation history

2. **Post-compaction verification** (per CLAUDE.md):
   - Stop and verify before taking file-modifying actions
   - Check `pwd` and `git branch`
   - Identify the active task document
   - Verify file scope before editing

3. **When creating a new branch for a task**:
   - Create it immediately with the specified name
   - Do not reuse an existing branch unless explicitly told
   - Keep branch names descriptive of their purpose

4. **When running long background jobs**:
   - Be aware that `git checkout` during background jobs can cause files to be committed to the wrong branch
   - Consider using `git stash` before switching branches
   - Verify branch before committing
