## Question and evidence contract

Do source and TF training diverge when pretrained parameters, Adam moments,
rates, rows and base random inputs agree, but resampling is recomputed from
each implementation's evolving state? Locate the first discrepancy and compare
its growth with a source-source tiny perturbation and binary64 controls.

The comparator is pinned Younis source b0e2fd54db7b6c36d70e8e701ddc6a3f3d5dee18,
using its actual MDPF model, trainer, loss, clipping and Adam. TF uses
BearingsNeuralReplay -> SourceFullTraining -> the existing transition,
IWSG/KDE and optimizer kernels. No production implementation is changed.

Only random-variable coupling adapters are diagnostic additions. Normal draws
are loc + scale*z; categorical draws use inverse CDF with a common uniform;
Von Mises uses the original source rejection sampler and the existing TF
rejection kernel with shared uniforms. Categorical inverse CDF is a coupling
of the same distribution, not a claim to reproduce torch.multinomial's seed
mapping. Proposal noise and initial noise are also shared. Samplers always
consume their own current weights, centers and bandwidths. No completed
resampling output may be shared between trajectories.

Adapter admission requires checks against the original source sampler on
identical inputs: normal/categorical reconstruction, original source rejection
formula, output/iteration agreement, own-state sensitivity, and repeatability.
Categorical interval checks establish the inverse-CDF mapping; empirical
frequencies are explanatory only. Rejection exhaustion (128), non-finite
values, failed controls, different starting state, or missing diagnostics veto
the affected trajectory. Ordinary finite source/TF discrepancy is a repair
trigger/localization result, not a continuation veto or automatic rejection
of the research direction.

The primary result is a descriptive time-indexed divergence record, including
loss, norm, gradient/parameter/moment discrepancies, ancestor disagreements,
proposal angle radius, circular state differences and sampling iteration counts.
The earliest divergence and its temporal relation to resampling are explanatory
diagnostics. Existing local tolerances (FP32 2e-5 absolute/relative, FP64 2e-9)
are localization flags, never learned-quality acceptance margins. Shared source
sensitivity cannot by itself establish replication or explain a final RMSE gap.
No method ranking, downstream noninferiority, full-training equivalence,
paper-wide completion or default change can follow from this diagnostic.
