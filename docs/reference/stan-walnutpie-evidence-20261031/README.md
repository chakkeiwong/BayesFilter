# Stan and Walnutpie monograph evidence

Selected completed-result records supporting `docs/chapters/ch26k_stan_walnutpie.tex`.
`index.json` records the original relative paths, sizes and SHA-256 hashes.
The bytes are copied unchanged. Dates inside each original manifest retain
their original meaning; the snapshot capture is October 31, 2026.

This is diagnostic/reporting evidence, not an executable runtime dependency.
It does not contain all raw draws or financial-model data and cannot alone
reproduce a chain. See the chapter and individual result notes for limitations,
especially the million-run author discrepancies and the full80 model-source drift.

To check the compact snapshot, run `python docs/reference/check_stan_walnutpie_evidence.py`.
