Twist is a separate Gaussian psi-APF comparator, not an LEDH or IAPF implementation. Primary source inspected: Guarniero, Johansen, Lee (2017), equations5--6 and Proposition1, local text lines211--300; one-step psi=g case lines430--464. Author code not locally found; no code-faithfulness claim. Use psi_t(x)=g_theta(y_t|x)^lambda for fixed nonnegative lambda. Positive lambda gives a Gaussian conditional with observation covariance R/lambda. The normalizer is N(y;HAx,HQH^T+R/lambda) times exp(c), where c=-(lambda-1)(o log(2pi)+log|R|)/2-o log(lambda)/2. Its derivative includes dc=-(lambda-1)tr(R^-1 dR)/2. With x0 included, the first weight is f(x0,psi1); subsequent weights are g/psi times f(x,psi_next), and the terminal future factor is1.
