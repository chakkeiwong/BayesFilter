# Source-support ledger

Audit date: 2026-09-14. The source classes below are based on inspected
technical text, not on title or abstract searches. `Direct` means that the
paper supplies an estimator, representation, or theorem that can change a
score-computation phase. `Adjacent` means that it can change proposal or
downstream inference design but does not itself estimate the declared score.

## Immediate verdict

The most consequential omission is Nemeth et al.'s direct KDM/Rao--Blackwell
score estimator. The next omissions are explicit PaRIS/Fearnhead smoothing
arms, continuous-likelihood particle filters, and iterated filtering for
simulation-only models. Twisted and multilevel particle filters are proposal
or discretization variance controls rather than score estimators, but they are
needed if the program claims to explain score error rather than only compare
derivative formulas. The singular-transition branch still requires a local
support derivation; none of these regular-HMM theorems closes that gap.
