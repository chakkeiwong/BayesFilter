# Structural A/B campaign evidence

This archive preserves all campaign result JSON, manifests, logs, retained-chain
and warmup tensors, trained-map checkpoints, observations, probe parameters,
selections, state history and failed attempts. Start with
terminal-review-20261024.md and state.json. The final chains are in
attempts/model_a-hmc-01 and attempts/model_b-reset-hmc-01. The latter supersedes
the failed original-precision Model B attempt; its draws are not concatenated
with the earlier attempt.

The only generated evidence omitted from Git is the 21 prepared particle-design
JSON arrays (about 185 MB). They remain in the originating checkout. Their exact
SHA-256 hashes, sizes, model, horizon and seeds are in design-inventory.json.
They were produced on CPU with TensorFlow 2.19.1, FP32, stateless random draws,
4,032 particles, and the committed make_structural_design implementation.
The reconstruction script verifies each generated byte sequence before saving
it and refuses to replace a conflicting existing file. From the repository root:

    /home/chakwong/anaconda3/envs/tf-gpu/bin/python docs/plans/artifacts/structural-ledh-ab-20261023-01/restore_designs.py

Use an environment containing the recorded TensorFlow version if that local
conda path is unavailable. The script deliberately hides GPU devices. An optional
--output-directory argument permits verification in a fresh temporary directory.
The archive records a successful reconstruction of all 21 designs in the
documentation closeout audit; reproducing their hashes does not rerun the
scientific experiment.

Absolute checkout paths in original manifests are historical provenance. The
original source commit plus per-file source hashes identify the code actually
run, including uncommitted campaign edits. Moving the archive or making a new
commit does not change that historical identity. Do not edit old manifests or
resume their launch commands blindly: the master checks current source and
selection identities. A new experiment needs a fresh versioned output root.

Sampling completion and posterior approximation accuracy are distinct. Model A
uses an exact Kalman endpoint and passed a refined posterior-mean comparison.
Model B uses a fixed finite-LEDH endpoint; its retained chains meet the stated
R-hat criterion, but agreement with the exact nonlinear model posterior remains
unestablished. Historical reference probes and unsuccessful attempts are kept
to make this limitation inspectable.
