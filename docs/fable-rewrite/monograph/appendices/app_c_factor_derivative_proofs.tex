\chapter{Factor Derivative Proofs}
\label{app:bf-factor-derivative-proofs}

This appendix remains a bounded placeholder for full Cholesky, QR, and signed update/downdate derivative proofs. The current monograph now distinguishes clearly between factor identities that are derived in-book, identities that are checked against source notes and tests, and primitives that are still cited or deferred rather than re-proved here. In particular, the ordered signed rank-one update/downdate recurrence used by the negative-weight SR-UKF branch is \emph{not} yet derived here; Chapter~\ref{ch:bf-square-root-sigma-point} therefore treats that derivative route as conditional unless an external primitive is supplied and reconstruction is checked directly.

\paragraph{Scope note.}
The placeholder status applies only to the signed update/downdate primitive. The ordinary QR and Cholesky branch identities in Chapter~\ref{ch:bf-factor-derivatives} remain valid smooth-branch tools for the positive-factor lanes.

Before this appendix is promoted beyond outline form, it should include:
\begin{itemize}
  \item the source MacroFinance labels for Cholesky derivative formulas;
  \item the QR perturbation equations used by the square-root Kalman backend;
  \item reconstruction identities connecting factor derivatives to covariance
    derivatives;
  \item code references to QR and Cholesky differentiated Kalman tests;
  \item MathDevMCP or manual proof-obligation results for each nontrivial step.
\end{itemize}
