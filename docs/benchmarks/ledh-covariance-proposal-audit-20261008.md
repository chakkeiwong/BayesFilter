The runtime computes analytical directional total derivatives, once per parameter. It uses no GradientTape, ForwardAccumulator, pfor, vectorized_map, NumPy runtime or alternate GPU implementation. CPU tests deliberately hide GPU; GPU runs enable and verify memory growth. Dense transport uses the repository exact chunk selector and rejects N>3000.

MathDevMCP audited the Cholesky reset, beta derivatives, Cayley map and total-score labels. Required terms/operations were found; all four returned `unverified`, with parser provenance/formalization limitations and requests for invertibility, dimensions, solve residuals and execution-boundary evidence. The proof of H invertibility above, SPD guards, stable tensor signatures, solve-residual tests and GPU/XLA tests address substantive local obligations. Parser limitations remain; the AST checker is not a theorem prover. Saved bounded response: `../plans/artifacts/ledh-covariance-implementation-20261008-01/mathdev-audit.json`.

Limits found and retained explicitly: common additive Q only; no nonadditive augmented UKF implementation; dense reset only; restricted four-direction Cayley basis; equal standardized coordinate radii; no adaptive ridge/clipping; only beta is fitted at fixed other controls; no repository canonical admission factory/tuning promotion; no same-data Zhao–Cui replication; no full fourth-moment accuracy or cross-model statistical guarantee. The beta validation artifact certifies scope, finite pilots and optimization termination, not model-score accuracy.

The mathematical formulas in the protected documentation baseline are preserved. The final edits update implementation status and add actual diagnostic evidence. A final source-label ledger and numerical records retain line/source hashes; neither substitutes for the derivations or executable checks.
